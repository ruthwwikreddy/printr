# Example Landing Page for Printr

This directory contains the original landing page code used for showcasing the Printr Autonomous Printing OS.

## How to reuse it:
1. Create a new route in your Next.js app (e.g., `src/app/landing/page.tsx`).
2. Copy the contents of `example-landing/page.tsx` into that file.
3. Ensure you have `lucide-react` installed in your project.
4. Adjust the links to point to your own deployed kiosk and admin panels.
